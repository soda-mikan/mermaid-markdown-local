# Changelog

All notable changes to this project will be documented in this file.

## 0.2.0 - 2026-09-27

- Matched the Quiet Light Mermaid palette to VS Code's neutral nodes and blue connectors.
- Added four text-size presets for the editor, Viewer, Mermaid, and exports.
- Added optional local `.docx` templates using a standalone `{{CONTENT}}` placeholder.
- Preserved template page settings, headers, footers, and Word styles during export.
- Rejected macro-enabled, oversized, malformed, and externally linked Word templates.

## 0.1.0 - 2026-09-21

- Added a two-pane Markdown editor and viewer.
- Added Mermaid rendering with selectable color themes, including Quiet Light.
- Added viewer-only mode and a collapsible Markdown cheat sheet.
- Added local file open, overwrite save, and save-as support.
- Added PDF, PNG, Word, and PowerPoint export.
- Packaged the complete application as one offline HTML file.
