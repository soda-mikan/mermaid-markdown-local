# Contributing

Small, focused pull requests are welcome.

1. Install dependencies with `npm ci`.
2. Edit files in `src/`.
3. Run `npm run verify`.
4. Open `dist/mermaid-markdown-local.html` in a browser and check the affected
   interaction manually.

Please do not add telemetry, analytics, remote fonts, CDNs, or other runtime
network dependencies. Privacy and single-file offline operation are core
project requirements.
